# MiMo 短发版参考与制作记录

按用户确认的CD工作室/雷霆大思考动画身份制作，保留原MiMo作为独立选项。短棕发橙色挑染、琥珀眼、白橙外套/爪章/腰带/白鞋。发夹遵循用户后续核定的小米mi标志，大写M是已撤回历史要求。

user-fullbody-reference.png为用户角色参考；confirmed-mi-emblem.png为用户核定标志。style-reference-obsolete-M.png只作为原动画Q版画风和比例依据，其中M标志不得复用。pose-sheet.png和九个pose-sources由image_gen生成并分格提取；原像素提取坐标与hash见generation-provenance.json，实际提示词见imagegen-requests.json，初稿保存在generation-history。

角色美术和品牌标志沿用仓库现有来源/署名边界，不因程序许可而成为MIT或获得额外商用授权。本次为用户要求的同人变体；未将原插画作者未知项写为已确认。
